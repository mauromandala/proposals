# Alma CRM dentro WordPress — schermate di proposta

Quattro schermate navigabili che mostrano come apparirebbe il CRM «Alma CRM» nel pannello di amministrazione di WordPress.

- `index.html` — Panoramica
- `richieste.html` — elenco delle richieste
- `scheda.html` — scheda di una richiesta
- `pipeline.html` — pipeline business travel

Si aprono direttamente nel browser, a partire da `index.html`; il menu laterale collega le schermate.

I prezzi e le destinazioni vengono dal catalogo di Alma Travel. Volumi, clienti e operatori sono dati di esempio inventati.
